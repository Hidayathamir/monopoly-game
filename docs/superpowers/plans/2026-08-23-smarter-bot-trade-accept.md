# Smarter Bot Trade Acceptance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rewrite the bot's `shouldAcceptTrade` so it evaluates trades strategically — property development (houses), color-set (monopoly) completion/breakage, cash-reserve safety, and a required value surplus — instead of comparing raw purchase prices.

**Architecture:** All logic lives in `src/logic/bot.ts` (`shouldAcceptTrade` plus three new private helpers `propertyValue`, `monopolyBonus`, `monopolyPenalty`). `shouldAcceptTrade` is called unchanged from `src/logic/gameReducer.ts:541`, so no other production file changes. Behavior change is verified at the unit level (vitest) and end-to-end (playwright against seeded bot trades).

**Tech Stack:** TypeScript (vitest unit tests, playwright e2e), custom seed fixtures generated by `scripts/print-trade-seed.ts`.

## Global Constraints

- `verbatimModuleSyntax` → use `import type` for type-only imports (add `type Space` to the existing import in `bot.ts`)
- `erasableSyntaxOnly` → no enums, no namespaces, no `const enum`
- Bot still never proposes trades — it only responds to incoming offers
- The bot is always the offer recipient (`offer.toId`); "received" = `offer.offerProperties` + `offer.offerCash`, "given" = `offer.requestProperties` + `offer.requestCash`
- E2E tests require `npm run build` first
- Unit: `npm run test:unit` (vitest). E2E: `npm run test:e2e` (playwright). Lint: `npm run lint`. Typecheck: `npm run typecheck`

## Assumptions (design decisions made where the spec was ambiguous)

1. **Reserve formula sign fix.** The spec's flow shows `bot.money - offerCash + requestCash < RESERVE`, but the bot *receives* `offerCash` and *pays* `requestCash` (see `applyTrade` in `src/logic/gameReducer.ts:867-889`). The correct post-trade money is `bot.money + offerCash - requestCash`; the plan uses the corrected formula.
2. **Hotel is `houses === 5` in this codebase**, not 4. `MAX_HOUSES = 5` and building at 4 logs `BuiltHotel` (`src/logic/gameReducer.ts:447`), `BoardGrid` renders a hotel when `houses === MAX_HOUSES`. So multipliers are keyed `0→1.0, 1→1.3, 2→1.6, 3→2.0, 4→2.5, 5→2.5` (the spec's "4 (hotel) = 2.5x" row is applied to both 4 and 5).
3. **`propertyValue` uses `getHouseCost(space, 0)`** (the first-level house cost) as the single `houseCost` argument to the spec's literal formula `price + houses * houseCost * multiplier`.
4. **"Color set" = `SpaceType.Property` spaces sharing the same `color` field.** Railroad/utility monopolies are intentionally out of scope (spec says "color set").
5. **Behavior replaces the old `received >= given` rule.** Equal-value swaps are now rejected; a ~10% surplus is required. Existing tests that encoded the old rule are updated: 3 unit tests in `bot.test.ts` and 1 e2e test in `trade-positive.spec.ts`.
6. **Mortgaged status is ignored** in valuation (not mentioned in the spec); a mortgaged property still counts its full `price` + house value.

(c) Replace the entire existing `shouldAcceptTrade` function (currently lines 86-93) with:

```typescript
function propertyValue(space: Space, houseCost: number): number {
  const multiplier = HOUSE_MULTIPLIERS[space.houses] ?? 1;
  return (space.price ?? 0) + space.houses * houseCost * multiplier;
}

function tradeValue(state: GameState, propertyIds: number[], cash: number): number {
  let total = cash;
  for (const id of propertyIds) {
    const space = state.board[id];
    if (!space) continue;
    total += propertyValue(space, getHouseCost(space, 0));
  }
  return total;
}

function monopolyBonus(state: GameState, offerProperties: number[], requestProperties: number[], playerId: number): number {
  let bonus = 0;
  for (const id of offerProperties) {
    const space = state.board[id];
    if (!space || space.type !== SpaceType.Property || !space.color) continue;
    const set = state.board.filter((s) => s.type === SpaceType.Property && s.color === space.color);
    const ownedAfter = set.filter(
      (s) => s.owner === playerId || offerProperties.includes(s.id),
    ).filter((s) => !requestProperties.includes(s.id)).length;
    if (ownedAfter === set.length && set.some((s) => s.owner !== playerId)) {
      bonus += MONOPOLY_GAIN_BONUS * propertyValue(space, getHouseCost(space, 0));
    }
  }
  return bonus;
}

function monopolyPenalty(state: GameState, requestProperties: number[], playerId: number): number {
  let penalty = 0;
  for (const id of requestProperties) {
    const space = state.board[id];
    if (!space || space.type !== SpaceType.Property || !space.color) continue;
    const set = state.board.filter((s) => s.type === SpaceType.Property && s.color === space.color);
    const currentlyOwned = set.filter((s) => s.owner === playerId).length;
    if (currentlyOwned === set.length) {
      penalty += MONOPOLY_LOSS_PENALTY * propertyValue(space, getHouseCost(space, 0));
    }
  }
  return penalty;
}

export function shouldAcceptTrade(state: GameState, offer: TradeOffer): boolean {
  const bot = state.players[offer.toId];
  if (!bot) return false;

  const receivedValue = tradeValue(state, offer.offerProperties, offer.offerCash);
  const givenValue = tradeValue(state, offer.requestProperties, offer.requestCash);

  const bonus = monopolyBonus(state, offer.offerProperties, offer.requestProperties, bot.id);
  const penalty = monopolyPenalty(state, offer.requestProperties, bot.id);

  const totalReceived = receivedValue + bonus;
  const totalGiven = givenValue + penalty;

  const postTradeMoney = bot.money + offer.offerCash - offer.requestCash;
  if (postTradeMoney < TRADE_RESERVE) {
    return totalReceived > totalGiven * LOW_CASH_SURPLUS_REQUIRED;
  }
  return totalReceived > totalGiven * TRADE_SURPLUS_REQUIRED;
}
```
