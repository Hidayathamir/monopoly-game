# Monopoly 2× Rent (Full-Set Doubling) E2E Test — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a deterministic, seeder-driven e2e test proving that a full color group doubles rent and the renter pays the doubled amount.

**Architecture:** A new generated fixture `e2e/fixtures/monopoly-rent-seed.ts` (built by `scripts/print-monopoly-rent-seed.ts` from `createSeededState`) seeds a `Resolving` phase where Bravo owes doubled rent ($100 on Boardwalk, base $50 × 2) to Alpha, who owns the full Dark Blue set. A new spec `e2e/monopoly-rent.spec.ts` creates a 2-player room, seeds that state, and asserts the prompt amount, the doubling log message, and the exact money transfer. No production code changes.

**Tech Stack:** Node `tsx`, TypeScript, Playwright. No new dependencies.

**Design doc:** `docs/superpowers/specs/2026-08-19-monopoly-rent-e2e-design.md` — read it for the rationale.

## Global Constraints

- No TS `enum` anywhere (`erasableSyntaxOnly`); use `const` objects + derived union types. `verbatimModuleSyntax` is on — type-only imports must use `import type`. `noUnusedLocals`/`noUnusedParameters` are on.
- Semicolons: `src/logic/*`, `src/data/*`, `server/*`, and `scripts/*` use them; `e2e/*`, `src/components`, `src/hooks`, `src/net` omit them. Match the file being edited.
- e2e specs and fixtures must NOT import `src/logic/*` or `src/data/*` at runtime — Playwright's ESM loader rejects the bare JSON imports there (`board-data.json`, `cards-data.json`). `import type { GameState }` from `src/types/game.ts` is safe (`types/game.ts` has no imports).
- Generated fixtures carry a `// GENERATED by npm run <script> — do not edit by hand.` header and are produced by running the script — never hand-edited.
- Wire values (message types, action types, phases, log keys) never change.
- The seeded state's `currentPlayer` is a server slot index; `validateStateForRoom` requires `players[i].id === i` for every joined slot and `players.length === joined slots`. A `Resolving` seed must have a non-null `pendingAction`.
- Board data: `src/data/board-data.json` id 39 (Boardwalk) `rent: [50, 200, 600, 1400, 1700, 2000]`, `color: "#00008B"`; id 37 (Park Place) `rent: [35, 175, 500, 1100, 1300, 1500]`, `color: "#00008B"`.
- Money formatting is compact `Intl.NumberFormat` (`src/data/currency.ts`): `100` → `$100`, `1100` → `$1.1K`, `1400` → `$1.4K`.
- `npm run build` = `tsc -b && vite build` (needed before any e2e run; `dist/` is served by the e2e server). `npm run test:unit` = vitest. `npm run test:e2e` = Playwright.

- Produces: `e2e/fixtures/monopoly-rent-seed.ts` exporting `monopolyRentSeed: GameState` — a pure literal with only an `import type { GameState }` line. This is the e2e-safe scenario fixture (see design doc).

- [ ] **Step 1: Write the generator script**

Create `scripts/print-monopoly-rent-seed.ts` (semicolons; modeled on `scripts/print-seed.ts`):

```ts
import { writeFileSync } from 'node:fs';
import { createSeededState } from '../src/logic/seed';
import { GamePhase, LogEventKey, PendingActionType } from '../src/types/game';

const BOARDWALK = 39; // id 39: rent[0] === 50, color #00008B
const PARK_PLACE = 37; // id 37: color #00008B (same Dark Blue group)

const state = createSeededState({
  players: [
    { id: 0, name: 'Alpha', money: 1000, passedGo: true },
    { id: 1, name: 'Bravo', money: 1500, passedGo: true },
  ],
  board: {
    [PARK_PLACE]: { owner: 0 },
    [BOARDWALK]: { owner: 0 },
  },
  currentPlayer: 1,
  turnOrder: [1, 0],
  phase: GamePhase.Resolving,
  pendingAction: {
    type: PendingActionType.PayRent,
    spaceId: BOARDWALK,
    amount: 50 * 2, // base rent doubled by the full color group
  },
  tradesEnabled: false,
});

// Seed the doubling message so the log explains why the rent is doubled.
state.eventLog = [
  { key: LogEventKey.MonopolyRent, params: { owner: 'Alpha', name: 'Bravo' } },
];

const out =
  "import type { GameState } from '../../src/types/game'\n" +
  '\n' +
  '// GENERATED by `npm run print-monopoly-rent-seed` — do not edit by hand.\n' +
  '// Alpha owns the full Dark Blue set (37 + 39); Bravo owes $100 on Boardwalk (base $50 x2).\n' +
  `export const monopolyRentSeed: GameState = ${JSON.stringify(state, null, 2)}\n`;

writeFileSync('e2e/fixtures/monopoly-rent-seed.ts', out);
console.log('wrote e2e/fixtures/monopoly-rent-seed.ts');
```

**Files:**

**Interfaces:**

- Produces: one Playwright test covering the doubled-rent scenario end to end.

- [ ] **Step 1: Write the spec**

Create `e2e/monopoly-rent.spec.ts` (no semicolons, matching the `e2e/*` convention):

```ts
import { test, expect } from './fixtures'
import { seedGame } from './helpers/seed'
import { monopolyRentSeed } from './fixtures/monopoly-rent-seed'

test('a full color group doubles rent and the renter pays the doubled amount', async ({ browser, serverUrl }) => {
  const context = await browser.newContext()
  await context.addInitScript(() => {
    localStorage.setItem('monopoly-language', 'en')
    localStorage.setItem('monopoly-currency', 'USD')
  })
  const contextB = await browser.newContext()
  await contextB.addInitScript(() => {
    localStorage.setItem('monopoly-language', 'en')
    localStorage.setItem('monopoly-currency', 'USD')
  })
  const pageA = await context.newPage()
  const pageB = await contextB.newPage()

  await pageA.goto(serverUrl)
  await pageA.fill('input[placeholder="Name"]', 'Alpha')
  await pageA.click('button:has-text("Continue")')
  const codeLocator = pageA.locator('[data-testid="room-code"]')
  await expect(codeLocator).not.toHaveText('—', { timeout: 5000 })
  const code = (await codeLocator.innerText()).trim()

  await pageB.goto(serverUrl)
  await pageB.fill('input[placeholder="Name"]', 'Bravo')
  await pageB.click('button:has-text("Join Room")')
  await pageB.fill('input[placeholder="Code"]', code)
  await pageB.click('button:has-text("Continue")')
  await expect(pageA.locator('text=Bravo')).toBeVisible({ timeout: 5000 })

  // Seed the decision point: Bravo is current on Boardwalk (39) and owes doubled rent.
  await seedGame(serverUrl, code, monopolyRentSeed)

  await expect(pageB.locator('[data-testid="sidebar"]')).toBeVisible({ timeout: 5000 })

  // The prompt shows exactly the doubled amount ($100 = $50 base x 2).
  const baseRent = monopolyRentSeed.board[39].rent![0]
  const doubled = baseRent * 2
  await expect(pageB.getByText(`$${doubled}`, { exact: true })).toBeVisible({ timeout: 5000 })
  await expect(pageB.getByRole('button', { name: 'Pay Rent' })).toBeVisible()
  await expect(
    pageB.locator('[data-testid="event-entry"]').filter({ hasText: /owns the full color group/ })
  ).toBeVisible()

  await expect(pageA.locator('[data-testid="waiting-for"]')).toContainText('Bravo')

  // Paying transfers exactly the doubled amount: Bravo 1500-100=1400, Alpha 1000+100=1100.
  await pageB.getByRole('button', { name: 'Pay Rent' }).click()
  await expect(
    pageB.locator('[data-testid="player-card"]').filter({ hasText: 'Bravo' })
  ).toContainText('$1.4K')
  await expect(
    pageA.locator('[data-testid="player-card"]').filter({ hasText: 'Alpha' })
  ).toContainText('$1.1K')
  await expect(
    pageB.locator('[data-testid="event-entry"]').filter({ hasText: /paid \$100 rent to Alpha/ })
  ).toBeVisible()
})
```

Notes (do not copy into the file):
- `getByText('$100', { exact: true })` matches only the `<strong>` amount node — the parent paragraph's text is `Pay rent $100`, so without `exact: true` Playwright would match both and throw a strict-mode violation. Player cards show `$1.5K` / `$1K`, so `$100` is otherwise unique.
- The doubling message is seeded into `eventLog` because the seed lands in `Resolving`; `ResolveSpace` will not run again. It is the scenario's history, matching how the bankruptcy fixture pre-computes its rent.
- The `MoneyChange` float animation briefly renders `+$100`/`-$100` inside the cards after payment; `toContainText('$1.4K'/'$1.1K')` targets the persistent card text and is unaffected.
- The paid-rent log text is `Bravo paid $100 rent to Alpha` (`resolveLogEntry` formats `amount` as `$100`).
