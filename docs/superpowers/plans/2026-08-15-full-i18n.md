# Full i18n (EN default) + Decoupled Currency — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Localize the game for English (default) and Indonesian with a user-facing language toggle, decouple currency (USD/IDR) from language, and migrate all UI/board/card/event-log text to react-i18next.

**Architecture:** react-i18next key-based dictionaries for all translatable text; money stored in canonical base units (dollars) with currency multiplier + formatting applied only at display time via a single currency-aware `formatMoney`; event log becomes structured `{ key, params }` entries localized at render; the reducer/server stay language- and currency-agnostic.

**Tech Stack:** TypeScript + React 19 + Vite + Vitest (jsdom for component tests) + Tailwind CSS v4. New deps: `i18next`, `react-i18next`.

## Global Constraints

- Base monetary unit = dollar (raw values in `board-data.json`: prices 60–400, starting money 1500, GO salary 200, jail fine 50).
- Currency multiplier applied ONLY in `src/data/currency.ts` `formatMoney`; no scaling in `board.ts`/`cards.ts`/`gameReducer.ts`.
- `formatMoney(amount: number | undefined, currency: Currency = DEFAULT_CURRENCY): string`.
- Translation keys are FLAT dotted strings (`"board.space.0"`, `"event.bought"`); i18next initialized with `keySeparator: false`.
- Default language `en`; default currency `USD`. Persisted keys: `monopoly-language`, `monopoly-currency`.
- `Space` and `Card` types lose `name`/`description`; resolve board names via `t('board.space.' + id)` and card text via `t('card.<deck>.<id>')` where `<deck>` is `chance` (ids 1–10) or `community` (ids 101–110).
- Event-log money params use exactly the keys `amount` and `netWorth`; space-name params use `spaceId`; card-text params use `cardId`. See the resolver in `src/i18n/log.ts`.
- `STATE_VERSION` in `src/hooks/useGame.ts` bumps from `5` to `6`.
- `npm run typecheck`, `npm run lint`, and `npm run test:unit` must pass at the end of every task.

```typescript
export type Currency = 'USD' | 'IDR'

export interface CurrencyDef {
  code: Currency
  multiplier: number
  locale: string
  currency: string
}

export const CURRENCIES: Record<Currency, CurrencyDef> = {
  USD: { code: 'USD', multiplier: 1, locale: 'en-US', currency: 'USD' },
  IDR: { code: 'IDR', multiplier: 1_000_000, locale: 'id-ID', currency: 'IDR' },
}

export const DEFAULT_CURRENCY: Currency = 'USD'

export function formatMoney(amount: number | undefined, currency: Currency = DEFAULT_CURRENCY): string {
  if (amount === undefined) amount = 0
  const def = CURRENCIES[currency]
  const value = amount * def.multiplier
  return new Intl.NumberFormat(def.locale, {
    style: 'currency',
    currency: def.currency,
    maximumFractionDigits: 0,
  }).format(value)
}
```

```tsx
import { createContext, useContext, useState, type ReactNode } from 'react'
import { DEFAULT_CURRENCY, formatMoney as formatMoneyFor, type Currency } from '../data/currency'

const STORAGE_KEY = 'monopoly-currency'

interface CurrencyContextValue {
  currency: Currency
  setCurrency: (c: Currency) => void
  formatMoney: (amount: number | undefined) => string
}

const CurrencyContext = createContext<CurrencyContextValue | null>(null)

function readSavedCurrency(): Currency {
  try {
    const saved = localStorage.getItem(STORAGE_KEY)
    return saved === 'IDR' || saved === 'USD' ? saved : DEFAULT_CURRENCY
  } catch {
    return DEFAULT_CURRENCY
  }
}

export function CurrencyProvider({ children }: { children: ReactNode }) {
  const [currency, setCurrencyState] = useState<Currency>(readSavedCurrency)

  const setCurrency = (c: Currency) => {
    setCurrencyState(c)
    try {
      localStorage.setItem(STORAGE_KEY, c)
    } catch {
      // ignore storage failures
    }
  }

  const value: CurrencyContextValue = {
    currency,
    setCurrency,
    formatMoney: (amount) => formatMoneyFor(amount, currency),
  }

  return <CurrencyContext.Provider value={value}>{children}</CurrencyContext.Provider>
}

export function useCurrency(): CurrencyContextValue {
  const ctx = useContext(CurrencyContext)
  if (!ctx) throw new Error('useCurrency must be used within a CurrencyProvider')
  return ctx
}
```

```typescript
import { initReactI18next } from 'react-i18next'
import en from './locales/en/translation.json'

const STORAGE_KEY = 'monopoly-language'
export const DEFAULT_LANGUAGE = 'en'

function readSavedLanguage(): string {
  try {
    return localStorage.getItem(STORAGE_KEY) ?? DEFAULT_LANGUAGE
  } catch {
    return DEFAULT_LANGUAGE
  }
}

i18n.use(initReactI18next).init({
  resources: {
    en: { translation: en },
    id: { translation: id },
  },
  lng: readSavedLanguage(),
  fallbackLng: DEFAULT_LANGUAGE,
  keySeparator: false,
  interpolation: { escapeValue: false },
})

i18n.on('languageChanged', (lng) => {
  try {
    localStorage.setItem(STORAGE_KEY, lng)
  } catch {
    // ignore storage failures
  }
})

export default i18n
```

- [ ] **Step 1: Create `src/i18n/log.ts`**

```typescript
import type { TFunction } from 'i18next'
import type { LogEntry } from '../types/game'

const MONEY_PARAM_KEYS = new Set(['amount', 'netWorth'])

export function cardKeyForId(id: number): string {
  return id >= 100 ? `card.community.${id}` : `card.chance.${id}`
}

export function resolveLogEntry(
  entry: LogEntry,
  t: TFunction,
  formatMoney: (amount: number | undefined) => string,
): string {
  const params: Record<string, string | number> = {}
  for (const [key, value] of Object.entries(entry.params ?? {})) {
    if (key === 'spaceId') {
      params[key] = t(`board.space.${value}`)
    } else if (key === 'cardId') {
      params[key] = t(cardKeyForId(Number(value)))
    } else if (MONEY_PARAM_KEYS.has(key)) {
      params[key] = formatMoney(typeof value === 'number' ? value : Number(value))
    } else {
      params[key] = value
    }
  }
  return t(entry.key, params)
}
```
